بسته‌های asset موشن گرافیک

هر چیزی که فیلم‌های موشن مرتباً لازم دارند: بافت‌های زمین، گرین سینمایی، و قلم مونوی ترمینال. همه با لایسنس آزاد (CC0 و OFL)؛ با تأیید چک‌سام دانلود می‌شوند و اگر بسته‌ای در انبار نباشد، طرح کد‌محور خودش جای آن را می‌گیرد و نبودش هیچ‌وقت رندر را نمی‌شکند. 

# install everything (recommended)
npm run textures
npm run assets

# or just one pack
npm run assets -- --only tex-metal043a

سرویس خودکار: موتور قبل از نوشتن پروژهٔ هر کار، نیازهای همان فیلم را از ورقهٔ بیت و پس‌زمینهٔ انتخابی درمی‌آورد و بسته‌های جاافتاده را خودش دانلود می‌کند — npm run assets -- --auto --for-job <id>. هر بسته پس از دانلود با حجم و SHA-256 پین‌شده تأیید می‌شود؛ فایل ناسازگار دور ریخته می‌شود و هرگز نصب نمی‌شود. مبدأ و لایسنس هر بسته در lib/assets.mjs ثبت است.
